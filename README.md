# Внутренний совет (inner-council)

Скилл для Kimi Work: контекстные художественные сцены из 24 внутренних голосов в духе Disco Elysium.

Версия источника: `0.1.0+local.20261111-140307`.

По умолчанию включён развёрнутый режим с частыми сценами. Голоса выбираются по контексту задачи, могут спорить, обращаться к пользователю и выступать несколько раз. Доступны тихий, короткий, обычный, развёрнутый режимы, один голос и полный совет.

## Скачивание

На странице репозитория нажмите **Code → Download ZIP**, чтобы скачать весь плагин одним архивом.

## Установка с помощью ИИ

Отправьте ссылку на этот репозиторий ИИ-агенту, который умеет скачивать файлы и работать с плагинами, и напишите:

> Скачай плагин inner-council из этого репозитория, проверь его структуру и подготовь к установке в Kimi Work.

В Kimi Work агент может скачать исходники, проверить их и зарегистрировать плагин в личном каталоге. После этого откройте вкладку **«Личные»** и нажмите **＋** на карточке «Внутренний совет». Установка подтверждается пользователем.

Если репозиторий станет приватным, одной ссылки будет недостаточно: агенту понадобится авторизованный доступ. Возможности других ИИ зависят от их инструментов и разрешений.

## Использование

После установки подключите «Внутренний совет» и попросите, например:

- «Включи внутренний совет и помоги разобраться в сложной задаче».
- «Обсуди это решение голосами, которые сейчас действительно уместны».
- «Переключи совет в тихий режим».
