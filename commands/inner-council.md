# Внутренний совет

Примени скилл `inner-council` и выполни запрос пользователя на управление советом.

Поддержи естественные варианты: включить обычный режим, выключить сцены («тихий»), вызвать все 24 голоса («полный совет»), оставить один голос, сделать сцены короче или развёрнутее. Если аргументы пусты, включи развёрнутый контекстный режим с частыми включениями — режим по умолчанию — и коротко подтверди это.

Если пользователь дал в аргументах тему для обсуждения, а не команду режима, создай подходящую контекстную сцену по этой теме и затем дай полезный итог.

Аргументы пользователя: `$ARGUMENTS`
